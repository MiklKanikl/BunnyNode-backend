Basic Node Properties

Every node in BunnyNode has several basic properties that define its appearance and behavior:

  • Position: x/y coordinates of the node in the canvas
  • Size: width/height of the node
  • Color: The fill color of the node

Rectangle Node

Rectangle shaped node with only basic properties. Created via R or menubar.

Ellipse Node

Ellipse shaped node with only basic properties. Created via E or menubar.

Image Node

Image node that allows you to insert and manipulate images within your diagram. Created via I or menubar.
